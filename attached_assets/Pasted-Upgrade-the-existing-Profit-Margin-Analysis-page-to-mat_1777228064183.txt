1. Add Margin Recovery Simulator near the top
--------------------------------------------------

Insert a new section directly after the Profit Margin Summary and before Opportunities.

Title:
Margin Recovery Simulator

Subtitle:
Model how changes in CAC, shipping, discounting and returns affect contribution margin and contribution profit.

Add CFO Insight:
“Margin is currently most sensitive to Meta CAC, shipping costs and discount depth. Use this tool to test which margin levers create the fastest recovery.”

Add sliders:

A. Meta CAC Change
Range: -25% to +25%
Default: 0%

B. Shipping Cost Change
Range: -20% to +20%
Default: 0%

C. Discount Depth Change
Range: -5pp to +5pp
Default: 0pp

D. Returns Rate Change
Range: -5pp to +5pp
Default: 0pp

E. Payment Processing Cost Change
Range: -2pp to +2pp
Default: 0pp

Use mock base assumptions:
Revenue = £124,500
Current contribution margin = 42.3%
Current contribution profit = £52,913
Contribution per order = £35.00
Orders = 1,512
Current estimated opportunity = £20,400

Projected outputs:
- Projected Contribution Margin
- Projected Contribution Profit
- Contribution Movement vs Base
- Contribution per Order
- Margin Risk Level

Dynamic interpretation:
If contribution improves:
“This scenario strengthens margin because cost improvements more than offset current pressure.”

If contribution weakens:
“This scenario weakens margin because cost increases or discounting absorb contribution.”

If margin falls below 40%:
“This scenario pushes contribution margin below the warning threshold and should trigger immediate action.”

Add compact insight:
Fastest lever to improve margin:
“Reducing Meta CAC by 15% would add approximately £9,500 of contribution next month.”

Add second compact insight:
Safest lever to improve margin:
“Reducing shipping costs by renegotiating carrier rates improves margin without affecting conversion.”
