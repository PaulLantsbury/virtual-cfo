Enhance the Opportunities page so it reads like a CFO execution plan rather than a ranked opportunity list.

No additional investment required
Requires supplier negotiation
Requires CRM setup
Requires campaign reallocation

Use muted styling consistent with existing UI tags.

These should communicate effort level and implementation type.


2. Add expected time-to-impact indicators

Add a small line beneath each opportunity description:

Examples:

Immediate impact (0–30 days)
Short-term impact (1–2 months)
Structural impact (2–3 months)

Ensure styling matches the tone of the app.


3. Add confidence indicators

Add a small confidence label to each opportunity:

Confidence: High
Confidence: Medium

Place this beneath the time-to-impact indicator.

Keep styling subtle.

Start with reallocating Meta spend and reducing discount depth.

what changes
