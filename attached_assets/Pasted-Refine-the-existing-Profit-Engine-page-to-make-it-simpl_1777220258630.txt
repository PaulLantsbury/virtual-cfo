Refine the existing “Profit Engine” page to make it simpler, more insight-led and easier for non-finance ecommerce founders to understand.

The page is currently good visually, but it feels too much like a finance dashboard. Rework the hierarchy so the key CFO headlines appear first and the page feels like an AI CFO explaining what matters.

Do not rebuild the page from scratch. Keep the existing visual style, components and mock data, but reorganise, rename and simplify the page.

Main objective:
Make the page answer these questions in this order:
1. Am I profitably trading?
2. How safe is that profit?
3. Why did profit change this month?
4. Where is revenue being lost before profit?
5. What should I do next?

9. Language rules

Across the whole page:
- use “profit” rather than “EBITDA” in main labels where possible
- keep EBITDA in smaller helper text where useful
- avoid technical accounting language in headlines
- use plain-English explanations
- make every section answer “so what?”
- keep copy shorter and more action-oriented

Examples:
Instead of:
“Contribution margin improved by 2.4pp”
Use:
“More of each sale is now turning into profit.”

Instead of:
“Fixed cost absorption is 61%”
Use:
“Overheads are using 61% of profit before overheads.”

10. Visual simplification

- avoid too many coloured cards in one area
- make the top summary visually dominant
- make charts secondary to the headline insight
- ensure there is enough white space between sections
- optimise for desktop but keep responsive behaviour
