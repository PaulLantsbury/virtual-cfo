## C. Persistent synthetic daily reporting data

This is a separate, agreed product-data stream for realistic charts and changing daily financial data. Start with the planning and read-only fit check; no Supabase company, schema, seed rows, scheduler, provider writer, hosting or deployment is authorized by this documentation entry.

Read [the full synthetic daily reporting-data plan](synthetic-daily-reporting-data-stream.md) and [the Shopify test-data journey](shopify-test-data-journey-2026-10-29.md). The initial fixture models a £500,000 annual net-turnover e-commerce business with seasonal gifting, roughly £38 AOV, 50% product gross margin, VAT, five synthetic employees and outsourced third-party fulfilment. The guidance now records editable local defaults for a £164,000 five-person employment budget, £60,252 outsourced fulfilment/packaging, marketing and other overheads; this deliberately produces a loss-making pressure scenario, not an invented healthy margin. No PII is used.

Sequence:

1. Inspect Supabase schema, RLS, company isolation, the existing Store D fixture and the canonical data paths used by actual charts.
2. Use a new dedicated company, preserving Store D and all existing stores. Use the guidance’s explicit net-turnover/AOV/VAT definitions, editable cost defaults and 24-month completed-history proposal; validate the isolated write path before remote application.
3. Design a deterministic, idempotent generator, reconciliation rules and run receipts; keep provider test semantics separate.
4. Build and validate locally, then propose any necessary staging schema/access change before applying it.
5. Seed isolated staging history, verify actual pages use canonical scoped reporting paths, then define an approved daily schedule.
6. Keep live Shopify and Xero acceptance independently tracked. Do not classify synthetic records as provider transactions.

**Exit:** an isolated staging company shows reproducible, daily-changing sales, VAT, gross profit, five-person payroll, fulfilment and operating-cost data on the real chart paths; reruns are idempotent; reconciliations pass; merchant scopes stay untouched.
