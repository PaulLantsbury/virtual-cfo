## Counting rule

**36 unique output/source-path families** below. Repeated appearances in a card, narrative, waterfall, tooltip and figures table are mapped to the same row. A series row covers every generated bucket and comparison point, not just a headline. The connected monthly EBITDA reference and the sample EBITDA path are separate because their inputs differ. User inputs/local records are not incorrectly called missing database links. Context dates, bucket counts, review horizons, axis ticks and decorative numbering are recorded separately below.

## Calculation/storage layers

The connected EBITDA reference uses the same authenticated history API as Profit: Supabase stored records → read-only canonical server calculation → strict browser composition. It is not cash. No bank/working-capital amount endpoint exists for this page. Cash sample math runs in webpage JavaScript through `cashPeriodView.ts`, `cashPerformanceModel.ts`, `trendContext.ts`, and `cashResilience.ts`; its source is local fixtures, not the selected company's database. `CashReviewPlan` stores sample records in browser localStorage, not Supabase.

## Context, controls and values that are not financial outputs

- Database-provided available months, evidence version and observed/source timestamps are validated metadata, not financial cells.
- Selected period dates, granularity, comparator, bucket count and comparison window are resolved controls. Each actual chart bucket would require matching source coverage.
- Sample current-bank date is fixed 11 October 2026, distinct from the selected historical period; not a live bank-feed timestamp.
- Weekly allocations use cumulative rounding of a monthly sample amount. Preserving pennies does not establish actual weekly cash timing.
- Axis ticks, bar positions/heights, common £ scale, colour and rounding are presentation calculations. They need no database rows, but the plotted values must have verified inputs.
- The three sample action ranks and qualitative impact-unknown labels are not measured financial benefits. Stock impact repeats C009 and unsettled money repeats C003; neither is a new saving.
- The local buffer limit and the sample 42-day saved outlook horizon are controls/validation constants. They are not a cash forecast or sourced balance.
- Review date, saved timestamp, due status, owner and completion checkbox are local workflow data. Marking done is not proof of a financial outcome.
- The current sample saved minimum outlook stays null; the current fixed sample as-of normally prevents a later cash-change amount. These conditional paths are included so the inventory does not hide them.
- Accounting readiness is a status-only API: it cannot supply or certify a cash amount.

## Source dependencies to connect before cash can be real

Dated eligible unrestricted accounts; opening/closing bank balances; matched inventory changes and valuation; debtor balances/collections; pending provider funds, reserves and payouts; supplier-credit movement; other operating working capital; separately classified tax/interest, investment, financing and other external bank movements; internal-transfer exclusions; and exact period coverage. Cash forecasts additionally need dated future commitments and settlements. Existing P&L journal activity alone must not be silently treated as an eligible bank reconciliation.

**No website/database/provider/feed changes were made for this audit.** Existing yellow labels describe the present limitation. A separate reviewed cash contract/reader is required before connecting these outputs.
