Root cause (confirmed)
The supabase_migrations schema and schema_migrations table did not exist on the production Supabase database. Replit's deployment pipeline uses this table to determine which migrations have already been applied. With it absent, it treated all 19 historical migrations as unrun and attempted to validate and replay every one of them — including migration 000000's discount_codes functional index, which its validator misrepresented as text_ops on a uuid column.

The migration SQL text fix from the previous attempt was correct but irrelevant — the validator was never reaching the updated text because it was replaying from scratch regardless.
