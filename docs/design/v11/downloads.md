# Version 11 downloads

[Download the editable Word specification and complete mockup ZIP](https://github.com/PaulLantsbury/virtual-cfo/releases/tag/design-v11).

This is a documentation-only download package, labelled pre-release to distinguish it from an application release. It does not deploy or activate any application capability.

The Word document is the approved v11 review copy. For implementation, start with the [searchable specification](README.md) and its individual linked images. All 33 images are stored directly in this repository so an agent checkout contains the visual references without an additional download.

The [manifest](manifest.json) records the Word document hash and each image hash. Historical report, planner and alternative-state examples use separate fictional scopes.

## Using another development environment

Use the `codex/restart-baseline` branch or explicitly bring this documentation package into the working branch. Files on the development branch are not automatically present in `main`, Replit or an older local checkout. Begin with `docs/design/v11/README.md` and the repository `AGENTS.md`.
