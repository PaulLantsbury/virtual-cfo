## Product boundary

An ecommerce AI CFO: explain profit and cash, identify evidence-backed risks and opportunities, recommend controlled actions and eventually track outcomes. Keep the existing dashboard framework. Focus on post-marketing contribution, accounting reconciliation and cash, rather than building multi-touch attribution, audience activation or detailed advertising tooling. Sam remains a separate project.

This is a dependency roadmap, not six sequential page redesigns. Cash design and account preparation can run alongside Shopify implementation. A dashboard is complete only when its supported sources, calculations, filters, commentary and failure states work together. Retain partial verified measures while later components are unavailable.

## Delivery operating model

One coordinator owns integration, final review, documentation, publication and the shared staging runtime. Use up to three supporting agents in the current session for independent work: data/calculations, application work and independent verification. Use disjoint file ownership or isolated checkouts; test the integrated result. More agents are not a substitute for agreeing shared definitions.

Each coding brief must specify outcome, included/excluded scope, acceptance cases, source dependencies, file ownership, stop conditions and deliverables. Continue through implementation, focused tests, fixes, review, GitHub save and local staging verification without routine “continue” requests. Group material decisions; continue independent work while awaiting answers. Routine reversible implementation choices within the approved design are delegated; financial policy, material product behaviour, accounts/spending, database changes and production remain Paul's decisions.

Measure package elapsed time, blocked time, rework and acceptance success; do not promise a multiplier. Longer runs depend on the local Mac/workspace staying available and usage limits. No new hosted environment, goal, recurring automation, paid capacity or production authority is established by this document.
