2. Acquisition Efficiency
Clarify exactly what the dashboard tile currently represents.

For now, define it as:

Meta CAC trend / channel acquisition efficiency signal

Formula:
Current period Meta CAC compared with prior period Meta CAC.

Meta CAC = Meta spend / new customers attributed to Meta

3. Refund Rate
Define Refund Rate clearly as:

Refund Rate = Refund Value / Gross Sales

Where:
Refund Value = sum of refunded order/subtotal value in the selected period
Gross Sales = sales before discounts, refunds and VAT/sales tax

Add a note that a future operational view may also show:
Refunded Orders / Total Orders

Operating Profit Estimate = Contribution after fixed operating costs

Shopify revenue/order data + Xero cost data + temporary assumptions where Xero is not yet connected.
