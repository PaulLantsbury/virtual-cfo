Add a new page to the app called “CFO Alerts”.

This page should let users see what their virtual CFO can monitor, including alerts and recurring CFO reports.

Important gating rule:
CFO Alerts is a Pro-only feature.

Free users should be able to view a rich preview of the full page, including example alerts, example reports and example monitoring rules, but they should not be able to enable, edit, configure or receive alerts.

Use mock data and local UI state only.
Do not build real email sending, background jobs or external integrations.

4. Alert Categories

Add alert category sections with toggle cards.

Categories:

Sales alerts:
- Daily sales below target
- Revenue down vs prior 7-day average
- AOV drops by more than 10%
- Orders fall by more than 15%

Margin alerts:
- Contribution margin below 40%
- Margin drops by more than 3pp
- Shipping cost per order rises by 10%
- Discount dependency exceeds 35%

Marketing alerts:
- Meta CAC rises by more than 15%
- Google ROAS falls below target
- Blended CAC exceeds target
- CAC payback exceeds 1.6 orders

Cash alerts:
- Cash runway below 3 months
- Working capital drag increases by £25k
- Inventory days exceed 90 days
- Supplier payments accelerate materially

Opportunity alerts:
- New opportunity worth more than £5k/month detected
- Recoverable contribution exceeds £25k/month
- Discount leakage increases by £10k
- Scenario opportunity exceeds £40k/month

Each alert card should show:
- toggle on/off
- category badge
- rule text
- threshold
- frequency
- notification method
- severity
- last triggered if applicable

Pro mode:
- toggles can be switched on/off using local UI state
- threshold/frequency controls can be changed if present

Free mode:
- show the cards and rules
- disable all toggles and controls
- add lock icon or “Pro only” label
